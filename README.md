# Test2DPlatformerDMC
Тестовый платформер с простейшими механиками,анимациями и UI, работа с UnityEvents, небольшой интеллект врагов.
**Задача в игре:** добраться до портала в конце уровня.
**Управление :** WASD - движение, прыжок Space , атаковать мечом по нажатию левой кнопкой мыши.
Монетки дают случаное число денег от 1-5. 
При падении или смерти автоматический перезапуск уровня после небольшой паузы.
